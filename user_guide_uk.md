# Інструкція користувача — Vireo Autonomous Agent Network

## 1. Що таке Vireo Autonomous Agent Network

**Vireo** — це відкрита координаційна платформа та панель керування (`Coordination & Control Plane`) для автономних AI-агентів поверх **A2A** (виявлення й взаємодія агентів через підписані картки `Agent Card`) та **MCP** (інструменти й дані). Кожне виконання задачі проходить через контракт зобов'язань, криптографічну перевірку підписів **Ed25519**, адресацію до конкретного агента та валідацію JSON-схеми.

## 2. Для кого створено систему

- **Розробники автономних AI-агентів та мультиагентних систем**, яким потрібен контрольований шар управління, динамічні картки агентів (`Agent Card`) та виконання контрактів.
- **Інженери з безпеки та AI-дослідники**, які тестують поведінку агентів при підміні даних, некоректній JSON-схемі, скасуванні та повторних спробах виконання.
- **Команди, що будують приватні локальні рішення**, де важлива генерація власного `did:vireo:...` та локальний підпис артефактів.
- **Технічні лідери та архітектори**, яким потрібне наочне підтвердження надійності A2A-взаємодії.

## 3. Ключові можливості

- **Машина станів контракту задачі:** послідовний процес `DISCOVER → PROPOSE → NEGOTIATE → COMMIT → EXECUTE → VERIFY → DONE` з обробкою винятків:
  - скасування `PROPOSE / NEGOTIATE / COMMIT / EXECUTE → CANCELLED`;
  - повернення до узгодження `NEGOTIATE → PROPOSE`;
  - повторні спроби `VERIFY → EXECUTE` (до 2 ретраїв) або фіксація помилки `VERIFY → FAILED`.
- **Динамічна реєстрація та ідентичність агентів:**
  - Створення підписаних карток `Agent Card` безпосередньо в інтерфейсі Streamlit.
  - Генерація пар ключів **Ed25519** і підписаного `did:vireo:...`.
  - Збереження агентів у локальному файлі `results/registered_agents.json`.
- **Призначення агентів та A2A Discovery:**
  - Фільтрація агентів за можливостями у боковій панелі (наприклад, `security_audit`).
  - Вибір цільового агента у списку **Target / Assigned Agent (A2A)** для запуску задач.
- **Контроль цілісності:** підпис результатів, хешування вихідних артефактів та валідація JSON-схеми.

## 4. Структура веб-інтерфейсу

- **Ліва бокова панель (`Vireo Control Plane`):**
  - Індикатори активних протоколів (*Ed25519 Signed DIDs*, *Contract Machine States*, *JSON Schema + Artifact Hash*).
  - **A2A Discovery:** фільтр пошуку агентів за `capability` та список верифікованих агентів з їхніми `did:vireo:...`.
  - Кнопка **Run Full System Benchmark**.
- **Основна робоча область:**
  - Вкладка **Submit & Verify Task**: вибір **Target / Assigned Agent (A2A)**, поле **Task Objective**, перемикачі сценаріїв (`Honest Agent Execution`, `Enable Vireo Verification`, `Simulate Bad Schema`, `Simulate Cancel`), кнопка **Execute Contract Task** та відображення статусу виконання (`Final Contract State`).
  - Вкладка **Register Task Agent**: форма створення нового агента (`Agent Name / Role`, `Capabilities`, `Agent Endpoint`) та кнопка **Register Agent**.
- **Права панель (`Latest Benchmark History`):** вердикти бенчмарку, `Fingerprint` (`baad76ec2455`) та підсумкова статистика.

## 5. Порядок використання (Windows)

### Крок 1. Запуск юніт-тестів та бенчмарку
Виконайте `.\run_vireo.bat` у терміналі.

### Крок 2. Запуск веб-інтерфейсу
Виконайте `.\run_ui.bat` у терміналі та відкрийте `http://localhost:8501` у браузері.

### Крок 3. Реєстрація кастомного агента
1. Перейдіть на вкладку **Register Task Agent**.
2. Вкажіть роль (наприклад, `security_auditor`), можливості через кому (`security_audit, schema_audit, integrity_check`) та endpoint.
3. Натисніть **Register Agent** для генерації `did:vireo:...` і ключів Ed25519.

### Крок 4. Запуск задачі
1. Перейдіть на вкладку **Submit & Verify Task**.
2. Оберіть зареєстрованого агента у списку **Target / Assigned Agent (A2A)**.
3. Введіть текст задачі у **Task Objective**, налаштуйте прапорці та натисніть **Execute Contract Task**.
