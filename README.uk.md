# Vireo Autonomous Agent Network

Інноваційна відкрита координаційна платформа та панель керування (`Coordination & Control Plane`) для автономних AI-агентів поверх **A2A** (виявлення й взаємодія агентів через підписані картки `Agent Card` з ідентифікаторами `did:vireo:...` та ключами Ed25519) та **MCP** (інструменти й дані).

Проєкт спирається на власний зареєстрований у реєстрі W3C метод децентралізованої ідентичності **`did:vireo`** і вирішує ключову проблему автономних агентних систем — **довіру, криптографічну підзвітність і перевірку цілісності результатів** замість «сліпого» виконання задач. Кожен запуск проходить через контракт зобов'язань, перевірку підписів, динамічне призначення агента та валідацію JSON-схеми.

## Ключові можливості

- **Власна ідентичність `did:vireo` та підписи Ed25519:** кожен агент має криптографічний ключ Ed25519, підписану картку `Agent Card` та ідентифікатор формату `did:vireo:...`, що дозволяє перевіряти походження й авторство дій.
- **Машина станів контракту задачі:** послідовність `DISCOVER → PROPOSE → NEGOTIATE → COMMIT → EXECUTE → VERIFY → DONE` із підтримкою відхилень:
  - скасування `PROPOSE / NEGOTIATE / COMMIT / EXECUTE → CANCELLED`;
  - повернення до узгодження `NEGOTIATE → PROPOSE`;
  - повторні спроби `VERIFY → EXECUTE` (до 2 ретраїв) або завершення з помилкою `VERIFY → FAILED`.
- **Динамічна реєстрація та A2A Discovery:**
  - Реєстрація підписаних карток `Agent Card` на льоту з власними ролями та можливостями (наприклад, `security_auditor` з `security_audit, schema_audit, integrity_check`).
  - Збереження агентів у локальному реєстрі (`results/registered_agents.json`).
  - Фільтрація агентів за можливостями у боковій панелі та вибір конкретного агента для виконання задачі.
- **Довіра та цілісність даних:** перевірка підписів агентів, хешування артефактів результату та контроль відповідності JSON-схемі.
- **Локальна автономність і приватність:** усі тести, генерація ключів і виконання задач працюють локально без передачі даних назовні.
- **Веб-інтерфейс керування (`Streamlit`):**
  - **Submit & Verify Task:** запуск задач із призначенням target-агента, власною метою (`Task Objective`), перемикачами чесності, валідації схеми чи скасування.
  - **Register Task Agent:** створення й підпис нових карток агентів у кілька кліків.
  - Перегляд історії бенчмарку на `http://localhost:8501`.
